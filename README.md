# Portfolio — Yoann Dexmier

Portfolio personnel de Yoann Dexmier, développeur web senior spécialisé JavaScript / React.

Construit avec **Astro 5** + **Tailwind CSS v4** + **Motion**, déployé sur **Vercel**.

## Démarrage

```bash
pnpm install
pnpm dev        # http://localhost:4321
```

## Commandes

```bash
pnpm dev          # Serveur de développement
pnpm build        # Build production
pnpm preview      # Prévisualisation du build
pnpm type-check   # Vérification TypeScript (astro check)
pnpm format       # Formatage Prettier
```

## Variable d'environnement requise

```
RESEND_API_KEY=xxx   # Formulaire de contact
```
